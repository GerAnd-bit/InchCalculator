# InchCalculator

A lightweight, offline-friendly calculator for feet and inches.

## Features

- Feet and inches calculations
- Fractional inch support
- Addition and subtraction
- Fraction simplification
- Calculation history
- Copy results
- Offline support (PWA)
- Installable on mobile devices
